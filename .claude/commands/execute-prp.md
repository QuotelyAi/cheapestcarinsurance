# Execute PRP

Implement a feature using the PRP file.

## PRP File: $ARGUMENTS

## Execution Process

1. **Load PRP** - Read and understand all requirements
2. **ULTRATHINK** - Plan comprehensively, use TodoWrite
3. **Execute** - Implement the code
4. **Validate** - Run validation commands, fix failures
5. **Complete** - Verify all items done, run final validation

Note: If validation fails, fix and retry.
