## Feature file: $ARGUMENTS

Generate a complete PRP for feature implementation.

## Research Process

1. **Codebase Analysis** - Search for similar features/patterns
2. **External Research** - Library docs, best practices
3. **Compliance Check** - Ensure feature meets insurance regulations

## PRP Generation

Using PRPs/templates/prp_base.md as template.

### Critical Context
- Documentation URLs
- Compliance requirements
- Existing patterns to follow

### Validation Gates
```bash
npm run lint
npm run type-check
npm run build
```

## Output

Save as: `PRPs/{feature-name}.md`

Score the PRP 1-10 for one-pass implementation confidence.
